# Racing Car on a Curved Track

## Description
A small 2D graphics animation of a car driving around a smooth
curved track. The project is built for ICS 3204 – Computer Graphics.

## Graphics Concepts Used
| Concept | Used For |
|---|---|
| DDA / Bresenham Line | Track edges and car details |
| Midpoint Circle Algorithm | Car wheels |
| Polygons | Car body and window |
| Bézier Curves | Shape of the track |
| Translation | Moving the car forward |
| Rotation | Turning the car along the track |
| Cohen-Sutherland Clipping | Keeping lines inside the screen |
